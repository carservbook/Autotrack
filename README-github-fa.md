# دفترچه سرویس خودرو — نسخهٔ پشتیبان (GitHub Pages) — v2.11.13

این ریپو **آدرس اضطراری** اپ «دفترچه سرویس خودرو» است؛ اگر مسیر اصلی
(api.carservbook.ir و autotrack.carservbook.ir) در دسترس نبود، اپ از همین آدرس باز می‌شود:

**https://carservbook.github.io/Autotrack/**

## تغییر v2.11.13 (سپر ایمنی داده)

- **راهنمای «حساب خالی»:** اگر بعد از ورود، سرور و دستگاه هر دو خالی باشند، اپ حالا
  راهنمایی می‌دهد که «اطلاعات به همان حسابی وصله که قبلاً با آن وارد شده بودی» — ریشهٔ
  گزارش «بعد از نصب مجدد TWA، اپ خام اجرا شد» ورود با حسابِ متفاوت بود.
- **خودترمیمی sync:** اگر گارد سرور پوش خالی را رد کند، اپ خودکار نسخهٔ سرور را می‌کشد.
- **حذف آگاهانهٔ آخرین خودرو** با تأیید سرور هماهنگ است (confirmWipe).
- خط آموزشی جدید در پنجرهٔ ورود: «با همان ایمیل/گوگلِ قبلی وارد شو».
- APP_VERSION → `۲.۱۱.۱۳`، نسخهٔ کش سرویس‌ورکر → `gh5`.
- سمت سرور (بستهٔ ورکر 2.11.13): بکاپ خودکار ۳ نسخهٔ آخر هر کاربر + گارد ضدپاک‌شدگی +
  مسیرهای نجات ادمین — داده‌ها دیگر در هیچ سناریویی بی‌بکاپ از بین نمی‌روند.

- اطلاعات این نسخه جدا از اپ اصلی روی دستگاه ذخیره می‌شود.
- کاربران مرورگر (نصب‌نشده) مثل قبل بعد از تأیید سلامت سرور اصلی خودکار به اپ اصلی
  منتقل می‌شوند (پل #hb). کاربران نصب‌کرده (TWA/PWA) عمداً همین‌جا می‌مانند.
- همگام‌سازی ابری از این نسخه با CORS ورکر فعال است و مثل اپ اصلی دو مسیره است.

## به‌روزرسانی این نسخه
فایل‌های جدید (index.html / sw.js / version.json / ...) را با «Add file → Upload files»
روی همین ریپو جایگزین کنید؛ GitHub Pages خودکار منتشر می‌کند (۱-۲ دقیقه).
فایل‌های مخفی موجود (مثل .nojekyll و .well-known) را پاک نکنید.

## تست بعد از انتشار
1. اپ نصب‌شده را کامل ببندید و دوباره باز کنید (دو بار، تا سرویس‌ورکر جدید بنشیند).
2. در پروفایل، نسخه باید «۲.۱۱.۱۳» باشد.
3. خروج از حساب → ورود مجدد با همان ایمیل/گوگل → همهٔ داده‌ها خودکار برمی‌گردند.
