# دفترچه سرویس خودرو — نسخهٔ پشتیبان (GitHub Pages)

این ریپو **آدرس اضطراری** اپ «دفترچه سرویس خودرو» است؛ اگر مسیر اصلی
(api.carservbook.ir و autotrack.carservbook.ir) در دسترس نبود، اپ از همین آدرس باز می‌شود:

**https://carservbook.github.io/Autotrack/**

- اطلاعات این نسخه جدا از اپ اصلی روی دستگاه ذخیره می‌شود.
- هر وقت سرور اصلی **واقعاً** در دسترس باشد (پاسخ واقعی API، نه کش دستگاه)، همین صفحه خودکار به اپ اصلی برمی‌گردد و اطلاعات منتقل می‌شود (پل #hb — گیت جدید v2.11.11).
- اگر سرور اصلی در دسترس نباشد، همین صفحه باز می‌ماند و نشانگر نارنجی پایین صفحه دیده می‌شود؛ با دکمهٔ «بازگشت به اپ اصلی» می‌توانید هر وقت خواستید دستی برگردید.
- همگام‌سازی ابری از این نسخه با CORS ورکر فعال شده است (v2.11.10) و مثل اپ اصلی دو مسیره است.

## به‌روزرسانی این نسخه
فایل‌های جدید (index.html / sw.js / version.json / ...) را با «Add file → Upload files»
روی همین ریپو جایگزین کنید؛ GitHub Pages خودکار منتشر می‌کند (۱-۲ دقیقه).
