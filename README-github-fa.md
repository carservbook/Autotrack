# دفترچه سرویس خودرو — نسخهٔ پشتیبان (GitHub Pages) — v2.11.12

این ریپو **آدرس اضطراری** اپ «دفترچه سرویس خودرو» است؛ اگر مسیر اصلی
(api.carservbook.ir و autotrack.carservbook.ir) در دسترس نبود، اپ از همین آدرس باز می‌شود:

**https://carservbook.github.io/Autotrack/**

## تغییر v2.11.12 (مهم برای اپ کافه‌بازار)

- **ورود با گوگل داخل اپ نصب‌شده درست شد.** قبلاً دکمهٔ گوگل مسیر نسبی را باز می‌کرد و
  روی همین شِل به 404 گیتهاب می‌خورد؛ حالا مسیر OAuth مطلق به سرور می‌رود و توکن با
  پل `#hb=` به همین دامنه برمی‌گردد و ثبت می‌شود.
- اگر کاربر در حین ورود با گوگل به صفحهٔ گوگل (Custom Tab) برود و بعد به اپ برگردد،
  اپ یک‌بار خودش را تازه‌سازی می‌کند و وارد شده است (بدون تلاش دوم).
- پیام خطای ورود گوگل (مثل لغو انتخاب حساب) حالا در اپ نمایش داده می‌شود.
- APP_VERSION → `۲.۱۱.۱۲`، نسخهٔ کش سرویس‌ورکر → `gh4`.

- اطلاعات این نسخه جدا از اپ اصلی روی دستگاه ذخیره می‌شود.
- کاربران مرورگر (نصب‌نشده) مثل قبل بعد از تأیید سلامت سرور اصلی خودکار به اپ اصلی
  منتقل می‌شوند (پل #hb — گیت v2.11.11). کاربران نصب‌کرده (TWA/PWA) عمداً همین‌جا
  می‌مانند تا تمام‌صفحه بمانند.
- همگام‌سازی ابری از این نسخه با CORS ورکر فعال است و مثل اپ اصلی دو مسیره است.

## به‌روزرسانی این نسخه
فایل‌های جدید (index.html / sw.js / version.json / ...) را با «Add file → Upload files»
روی همین ریپو جایگزین کنید؛ GitHub Pages خودکار منتشر می‌کند (۱-۲ دقیقه).
فایل‌های مخفی موجود (مثل .nojekyll و .well-known) را پاک نکنید.

## تست بعد از انتشار
1. اپ نصب‌شده را کامل ببندید و دوباره باز کنید (دو بار، تا سرویس‌ورکر جدید بنشیند).
2. در پروفایل، نسخه باید «۲.۱۱.۱۲» باشد.
3. «ورود با گوگل» → انتخاب حساب → بازگشت خودکار به اپ، وارد شده.
